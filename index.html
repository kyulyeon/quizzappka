참가자 0

    Firebase 연결 한 번만 설정하면 됩니다

    1. console.firebase.google.com → 프로젝트 추가
    2. 빌드 → Realtime Database → 데이터베이스 만들기 (테스트 모드로 시작)
    3. Authentication → 시작하기 → Sign-in method → Anonymous 사용 설정 (필수)
    4. 프로젝트 설정(⚙) → 내 앱 의 "SDK 설정 및 구성" 코드를 통째로 복사 → 아래에 붙여넣기
      databaseURL 줄이 없어도 괜찮아요 — 프로젝트 ID로 자동으로 찾습니다.
    5. 아래 보안 규칙 복사 → Realtime Database → 규칙 탭에 붙여넣고 게시
    아직 인식된 값이 없습니다.
    보안 규칙 
    
      
    
        규칙을 꼭 넣어야 점수 조작과 다른 사람 답 위조가 막힙니다.
        규칙 없이(테스트 모드)도 게임은 돌아가지만, 시청자가 점수를 바꿀 수 있어요.
